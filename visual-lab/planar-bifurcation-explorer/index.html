    Mathematical and numerical notes

    Which events are generic? In a generic one-parameter family of planar vector fields, the local equilibrium bifurcations are saddle-node and Hopf. Transcritical and pitchfork crossings require an invariant structure or symmetry. Folds of periodic orbits and SNIC onset are global events: they depend on the organization of trajectories beyond a single equilibrium.

    Equilibria, nullclines, and stability. An equilibrium is an intersection of the two nullclines f(x, y; r) = 0 and g(x, y; r) = 0. The eigenvalues of the Jacobian at that point describe local contraction, expansion, and rotation. A saddle has one eigenvalue on each side of the imaginary axis, so it is unstable overall, with one locally attracting and one locally repelling direction.

    Reading the trace-determinant diagram. Each equilibrium contributes one point on the current parameter slice. The two side equilibria of the pitchfork have the same trace and determinant. Their paths are drawn a few pixels apart so both are visible, and their markers point to the same spectral coordinate. The periodic-orbit trace and determinant come from the Jacobian evaluated at successive phases. The colors classify those individual matrices. In the Hopf normal forms, both quantities are constant around the orbit, so it appears as one point on each parameter slice. The transverse Floquet multiplier measures whether perturbations shrink over a full lap, even when the loop passes through an unstable region.

    Reading the state-space diagram. Each equilibrium traces a branch in (x, y, r). Each periodic orbit is a loop in the current parameter slice. Loops at successive parameter values form a surface. Solid paths are attracting, dashed paths are unstable, and dotted paths mark critical or semistable objects.

    Periodic orbits. The supercritical Hopf normal form has an attracting orbit of radius ρ = √r for r > 0. The subcritical normal form has a repelling orbit of radius ρ = √(−r) for r < 0. The bounded subcritical family adds a quintic term and has an attracting outer orbit near the Hopf point. For the homoclinic preset, periodic-orbit paths are approximated numerically. For a custom system, the phase portrait and both diagram views show the limit cycles the search finds. Narrow the plot window around a cycle if it is small compared with the full phase portrait.

    Parameter sweeps. Each fixed value of r defines an autonomous system. During a sweep, the display changes that system gradually to show the family. A moving particle during the sweep should therefore be read as a visual guide through nearby phase portraits, not as a solution of any one fixed autonomous equation.
